# 사업성과 임팩트 검토

## 기준 선택

기업 단계·문서 목적·자금조달 목적에 맞는 항목만 적용한다. 초기 기업에 성장기업의 실적을 요구하거나 모든 기업에 VC 투자·구독·고속 확장을 강제하지 않는다. 대상 투자자가 정해지지 않았다면 미정으로 표시하고 적합성 판단의 한계를 남긴다. 실제 투자자의 피드백이 아니면 자료 기반 내부 모의 검토로 표시한다.

| 영역 | 판단 질문 | 확인할 내용 |
|---|---|---|
| 전달력 | 누구에게 무엇을 제공하는지 이해되는가? | 제공물·사용 상황·현재 제공 상태 |
| 고객과 대안 | 고객이 해결에 돈을 쓸 이유가 있는가? | 문제 빈도·기존 비용·대안·구매자·구매 근거 |
| 수익과 실행 | 제공·판매를 반복할 수 있는가? | 가격·판매량·직접 원가·필요 인력·현금·영업 경로 |
| 시장과 경쟁 | 실제로 접근할 고객과 선택받을 이유가 있는가? | 고객 범위·접근 방법·같은 업무의 대안 비교·방어력 |
| 사회문제와 대상 | 누구에게 어떤 문제가 얼마나 중요한가? | 대상·지역·불편 또는 피해·당사자의 요구·현재 상태 |
| 변화와 기여 | 사업의 활동이 어떤 변화를 만드는가? | 활동 → 직접 산출 → 수혜자의 변화, 다른 영향 요인·부작용 |
| 측정과 근거 | 변화를 어떤 자료로 확인할 수 있는가? | 지표·단위·대상·기준선·기간·수집 방법·출처·한계 |
| 성장과 미션 | 사업 확대가 임팩트에 어떻게 연결되는가? | 서비스 접근성·품질·수혜자 범위·확대 비용·목표 충돌 |
| 투자자 관점 | 이 기업에 이 자금이 적합한가? | 사업 단계·투자자 유형·필요 자금·사용처·달성 목표·미션 적합성·회수 논리 |

사업의 긍정적 가능성과 근거 수준을 각각 기록한다. 참여자 수·공급량 등 직접 산출과 생활·환경의 변화를 구분하고, 변화 전부를 자사 기여로 단정하지 않는다. 중요한 지표부터 선택하며 근거 없는 화폐 환산·종합 점수는 만들지 않는다.

매출·보조금·차입·투자금 등 자금의 성격을 구분한다. 시장 규모와 자사 매출 목표도 구분하며 수치에는 기간·단위·입력 근거·산식을 붙인다. 법적 지위·지원 자격이나 투자자의 의사를 자료 없이 추론하지 않는다.

## 평가에서 개선으로

판정은 강점·조건부·약점·판단 유보를 사용한다. 근거는 가설·간접 근거·직접 확인 등 실제 확인 범위를 설명한다. 미확인을 실패로 처리하거나 총점으로 중대한 제약을 상쇄하지 않는다. 점수는 요청받은 경우에만 기준을 밝히고 사용한다.

각 보류 사유를 [기획 작성양식 B부](planning-worksheet.md)에 연결한다. 우선순위는 판단 영향·선행조건·실행 비용과 시간으로 정하고, 필요한 과제만 남긴다.

| 원인 | 개선 행동 | 복귀 지점 |
|---|---|---|
| 설명·구성 | 제공물·고객 변화·핵심 답을 구체화 | 원고 |
| 근거 부족 | 원자료·반대 근거·적용 범위 확인 | 조사 |
| 수치 오류 | 입력·단위·기간·산식·시나리오 정정 | 계산 |
| 사업 구조 | 고객·상품·판매·가격 대안과 미션 영향 비교 | 사업 논리 |
| 실제 효과·구매 미확인 | 검증 방법과 사전 판정 기준 정의 | 검증 과제 |

투자자 관점의 개선 제안도 회사의 목표·자원·미션과 대조한다. 새로운 사업 대안은 실적이 아닌 제안으로 기록한다. 실증 과제에는 관찰 대상·방법·기간·담당·비용·실행 조건과 통과·실패·유보 기준을 결과 확인 전에 적는다.

재검토에서는 변경 전 보류 사유, 실제 변경·새 근거, 달라진 판단, 남은 조건을 비교한다. 결과가 가설을 반박하면 가설과 계획을 수정하며 판정 기준을 사후에 바꿔 통과시키지 않는다. 계획 수립·문구 개선만으로 검증 완료를 선언하지 않는다.
